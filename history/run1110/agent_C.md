## 五、本期方法要点（供 SOURCES.md 增补）

1. **河南**：列表期与详情期分离——`http://hnjs.henan.gov.cn/YYYY/MM-DD/<id>.html` 会 301 到 https，须 `curl -L`；详情页「发布日期：YYYY-MM-DD」为唯一发布时间口径，列表页 11-09 条目详情亦为 11-09，无滞后。
2. **安徽**：`/site/label/8888` 的**必填参数**为 `action=list&isDate=true&dateFormat=yyyy-MM-dd&type=4&catIds=<catId>&file=/jh4/zjt/xxgk/publicInfoList_newest2022`（外加 Referer 与 `X-Requested-With`）；只传 `catId`（单数）或缺少 `action=list` 一律返回「系统繁忙」。栏目 catId 从 `/6804621/6991.js` 的 `var catalogs` JSON 目录树直取（行政规范性文件 43797541、其他政策文件 43797551、政策文件 43794731、公示公告 43796261）。
3. **江西**：`-articleList.json` 条目字段 `pubDate`（分钟级）、`metadata.xxgk_filenumber`（文号）、`metadata.xxgk_cwrq`（成文日期）、`urls` 为 JSON 字符串需二次解析取 `pc`。**注意排序非严格倒序**（11-09 条目排在 11-06 之后第 4 位），判窗口须逐条读 `pubDate`，不能只看首条。
